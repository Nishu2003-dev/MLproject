Smart Preprocessing Pipeline

Handles missing values via median/mode imputation, one-hot encodes categoricals, and standard-scales numericals — all in a single sklearn Pipeline.

GridSearchCV Tuning

Hyperparameters for all 8 models are optimized using 3-fold GridSearchCV. The best params are automatically applied before final training.

Artifact Persistence

Trained model and preprocessor are serialized as .pkl files using dill, enabling fast inference without retraining.
